# 第 12 步：机械臂返回 / 下一轮（RETURN）

机械臂先升到安全高度，沿当前侧回到车尾，再横移到左侧初始待命位，准备取下一件货；全部装完则结束本批任务。

## 输入

| 来源 | 说明 |
|------|------|
| 当前侧位置 | 放货后可能在左或右轨 |
| 回家目标 | 车尾左侧初始位 |

## 处理

1. 升到安全高度 → 沿当前侧回车尾 → 横移到左侧初始位（多段）  
2. `retract`  
3. 保存本轮 `round_data`，`round_index++`  
4. 若还有货物：加载下一件到孪生；否则 `finished`  

第 2 轮起自动跳过：3.2 雷达、4–7、8.1。

## 输出

- PLC 运动弹窗：返回多段路径  
- 进度：`completed / total`  
- 下一轮从第 2 步（货托偏移）再开始  

## 按钮

本步 DONE 且仍有货时，「执行下一步」进入下一轮第 2 步；全部完成则流程结束，下一步按钮禁用。
