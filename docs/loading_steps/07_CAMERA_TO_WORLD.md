# 第 7 步：角点转 WORLD（CAMERA_TO_WORLD）

把图上的角点像素，结合深度和拍摄时相机在世界里的位置，算出车板各角在场地坐标系里的三维坐标。

**仅首轮**。

## 输入

| 来源 | 说明 |
|------|------|
| 像素点 | 第 6 步 `image_points` |
| 深度 | 第 5 步 depth + 采样窗口 |
| 动态外参 | 拍摄瞬间相机 WORLD 位姿（臂位姿 × 安装外参） |

本步**不移动机械臂**。

## 处理

1. `(u,v) + depth + T_world_camera` → 各角点 WORLD XYZ  
2. 实验室路径可直接用已算好的世界坐标  
3. 写入 `round_data.camera_world_corners`，更新孪生车辆角点  

## 输出

- `world_points`：P1…Pn 的 WORLD 坐标  
- 孪生场景：车板角点可视化  
- 模块证据：`CAMERA_WORLD`  

后续 8.1 规划**只使用本步相机最终 WORLD 角点**（不用雷达粗点做板型判断）。

## 实验室模式：PLC 走位与相机最终角点

实验室模式不走现场的单一拍摄位，而是按 `P3/P4、P1/P2` 两组访问顺序执行：

1. 雷达角点已先通过实验室雷达外参转换到 WORLD，并计算每组中心点。
2. 使用实验室相机外参 `T_E<-C`、PLC 参考姿态和相机光轴反算每组实际 PLC 的 X/Y；只有相机工作姿态固定为 `Z=380 mm`、`R=-80°`，X 不写死。
3. PLC 到位后拍 RGB-D，YOLO 输出两个图像角点，深度针孔模型先还原相机坐标，再用拍摄瞬间 PLC 位姿与 `T_E<-C` 转换到 WORLD。
4. 相机 WORLD 角点是最终角点；缺失点逐点使用雷达 WORLD 点兜底，并保留来源字段。

现场模式仍使用原有的角点识别与动态相机 WORLD 转换配置，不读取实验室访问规划器或实验室雷达标定。
