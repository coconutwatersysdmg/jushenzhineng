# 第 8.1 步：车板规划（INITIAL_SPACE_PLAN）

根据相机得到的车板四角世界坐标，判断平板还是高低板，并在板上划出两列、每格约 1.2 米的可放货盲码区域。

**仅首轮**。用相机最终 WORLD 角点建盲码区。

## 输入

| 来源 | 说明 |
|------|------|
| `camera_world_corners` | 第 7 步 |
| 规划参数 | 行长 1.2m、高低板阈值、借位上限等 |

本步**不移动机械臂**。

## 处理

1. 判断平板 / 高低板  
2. 按车头→车尾生成两列 × 1.2m 区域盲码  
3. 高低板边界做最小借位优化  
4. 初始化 `SpaceManager` 可用 / 占用空间  

## 输出

- `round_data` / 孪生：`regions`、`available`、`borrow_plan`、板型几何  
- 右侧「空间与补偿」表  

第 2 轮起跳过本步，复用首轮车板模型。
