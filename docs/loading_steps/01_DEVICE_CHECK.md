# 第 1 步：外接设备连接检查（DEVICE_CHECK）

## 输入

| 来源 | 说明 |
|------|------|
| 运行模式 | `sim` / `lab` / `field`（决定 Mock 或真机适配器） |
| PLC | `plc.connect()` |
| 雷达 | `radar.probe()`（不采点云，只查程序/配置） |
| 相机 | `camera.connect()`（D435i）或 Mock `probe()` |

装载计划在点「开始」时已展开并 `STAGED`，本步只做设备。

## 处理

1. 依次探测 PLC、RADAR、CAM_PICK  
2. 更新孪生设备状态 + 运行日志（每台 SUCCESS/FAILED）  
3. 汇总 `all_online`；失败标 warning，**不阻断**下一步  

## 输出（看哪里）

- **顶栏「外接设备」**：`● 已连接` / `● 未连接` / `○ 未检测`（悬停看原因）  
- **左侧「外接设备连接状态」表**：状态 + 探测说明  
- **运行日志**：`DEVICE_CHECK` 逐条 + 汇总  
- `round_data.device_check`：完整探测结果  

判定要点：

- **PLC**：Modbus TCP 接通且寄存器可读，才算已连接  
- **雷达**：本机网卡必须有配置的 `host_ip`（不是“仓库里有 exe 就算连上”）  
- **相机**：D435i 真正打开成功才算已连接  

## 按钮怎么走

| 操作 | 效果 |
|------|------|
| 开始 | 开会话 / 计划就绪，**并立刻执行本步**；跑完流程格为 **DONE**（不是一直 RUN） |
| 执行下一步 | 从第 2 步起每次只跑一格 |

流程格语义：`DONE`=已结束，`RUN`=正在执行，`NEXT`=当前待点下一步，`WAIT`=未到。
